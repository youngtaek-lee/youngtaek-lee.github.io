## StatCounter

개인적으로 사이트에 누가 들어오는지 간단하게 알 수 있을까 해서 찾아보다가, 간단하게 로그 추적해주는 사이트를 찾게 되었다. 사이트가 GitHub Pages 기반 정적 호스팅이라 IP까지 보려면 어떤 방법이 있는지 하나씩 비교해봤다.

### GitHub Pages는 자체 로그가 없다

깃헙 페이지는 자체 로그가 없기 때문에 로그를 남기고 확인하려면 외부의 도움을 받아야 한다.

- **Cloudflare**: 도메인 앞단에 프록시로 세워서 요청을 거치게 하는 방식. 요청 단위 로그(Logpush)까지 볼 수 있지만 유료 플랜부터 지원하고, 도메인 네임서버 자체를 Cloudflare로 옮겨야 해서 기존 GitHub Pages 배포 구조를 건드려야 한다는 게 부담이었다.
- **GoatCounter**: 프라이버시 지향 분석 도구라 무료지만 국가 단위로만 뭉뚱그려 보여준다. 좀 더 자세하게 볼 수는 없는 거 같다.
- **StatCounter**: 무료 플랜으로 월 5,000세션까지 지원하고 실시간 방문자 로그(Visitor Activity)에서 IP·ISP·위치·리퍼러·체류시간이 방문 건별로 그대로 찍힌다. 데이터 보관은 14일뿐이라는 제약이 있다.

### StatCounter 세팅

statcounter.com 가입 후 URL을 등록한다. 추적 방식은 세 가지가 있는데 invisible tracking을 선택했다.

- **Visible Counter**: 방문자 수 카운터를 숫자 그대로 화면에 위젯처럼 노출하는 방식.
- **StatCounter Button**: StatCounter 로고 버튼을 페이지에 붙이는 방식. 클릭하면 통계 페이지로 연결되고, 역시 화면에 노출된다.
- **Invisible Tracking**: 화면엔 아무것도 표시하지 않고 백그라운드에서 스크립트만 돌아가는 방식. 방문자 눈에는 안 보인다.

선택 후 발급된 스크립트를 심어주면 끝이다.
이 사이트는 SPA 구조라 한 곳에만 스크립트를 넣으면 모든 페이지 이동이 잡힌다.

### IP 위치는 부정확

실제로 테스트해보니 방문자 위치가 광주로 나왔는데 실제 위치가 아니었다. IP 지오로케이션은 실제 접속 위치가 아니라 통신사가 그 IP 대역을 등록해둔 지역 기준이라, 와이파이를 쓰거나 하면 다르게 나오는 듯하다.
